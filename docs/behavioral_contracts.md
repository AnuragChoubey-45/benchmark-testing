# Behavioral contracts

These are intentionally documented as *oracle evidence*, not as configuration that the harness must require from a human.

- Premium customers receive a 20% discount.
- Regular customers receive a 5% discount.
- Premium customers receive free shipping at subtotal >= 500.
- Regular customers receive free shipping only at subtotal >= 1000.
- Only the `admin` tier can access admin functionality.
- Premium customers can view reports.
- Exact available inventory can satisfy an order.
- Remaining inventory cannot be negative.
